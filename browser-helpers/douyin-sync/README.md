# Easel 抖音历史作品同步助手

此 Chrome Manifest V3 扩展只读取用户已打开的 `https://creator.douyin.com` 页面中当前渲染的作品信息，并把扫描结果发送到本机 Easel 的短时同步会话。扩展不自动登录、不读取 Cookie 或密码，不调用创作者中心私有接口，也不执行发布或互动。

## 使用步骤

1. 打开 Easel 账号页 → 抖音宠物账号 →「首次账号诊断」。没有历史作品时点「从抖音创作者中心同步」；也可以从「历史内容与导入」页直接启动。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启「开发者模式」，选择「加载已解压的扩展程序」，选中此目录 `browser-helpers/douyin-sync`。
3. 从 Easel 复制会话码，在 Chrome 扩展弹窗粘贴并点「检测当前页面并连接」。主应用会收到扩展连接状态；Chrome 不允许网页直接枚举已安装扩展，所以必须由扩展主动握手。
4. 回到 Easel 点「打开抖音创作者中心」。系统会新开作品管理页；用户本人在页面中扫码或登录。Easel 和扩展不接触登录凭证。
5. 登录后在作品管理 / 内容管理 / 视频列表页面打开扩展，点「检测当前页面并连接」。Easel 会显示未登录、找不到标签页、不支持页面或“可扫描”等状态。
6. 在扩展点「开始扫描历史作品」。扩展会在可见作品列表辅助滚动，并尝试点击明确的“下一页”控件（最多 10 页）；如果页面没有可识别分页控件，用户手动翻到下一页，再重复扫描。
7. 扫描完后在扩展点「返回 Easel 生成预览」，切回 Easel 检查总行数、新增、更新、重复、错误、缺失字段和作品列表，再点「确认导入」写入。

## 读取字段

扩展只从页面 DOM 尝试读取作品 ID、标题、发布时间、视频时长、播放量、点赞、评论、收藏和分享。页面未显示的数据保持空值；页面明确显示 0 时保留为 0。作品主体、内容来源、Hook 和策略分类不会由扩展猜测。

页面结构由抖音控制，可能随版本变化。如果识别不到作品，请停止同步并改用 Easel CSV/XLSX 导入或手动录入。未扫描的页面不代表账号没有作品。

## 本地数据与访问范围

- 扩展仅有 `activeTab`、`scripting` 和 `storage` 权限，且只在用户主动打开扩展时读取当前标签页。
- 只向 `localhost:7860` 或 `127.0.0.1:7860` 发送预览数据；会话码限时并绑定抖音业务账号。
- 未提交前临时记录保存在 Chrome 当前浏览器会话的扩展存储中；生成预览后扩展会清除暂存扫描记录。
- Easel 在用户确认前不会将预览记录写入历史作品表；过期会话需回 Easel 重新创建。
