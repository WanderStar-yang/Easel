# Easel 抖音历史作品同步助手

此 Chrome Manifest V3 扩展只读取用户已打开的 `https://creator.douyin.com` 页面中当前渲染的作品信息，并把扫描结果逐页保存到本机 Easel 的账号隔离同步会话。扩展不自动登录、不读取 Cookie 或密码，不调用创作者中心私有接口，也不执行发布或互动。

## 使用步骤

1. 打开 Easel 账号页 → 抖音宠物账号 →「首次账号诊断」。没有历史作品时点「同步抖音数据」；也可以从「历史内容与导入」页直接启动。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启「开发者模式」，选择「加载已解压的扩展程序」，选中此目录 `browser-helpers/douyin-sync`。
3. 从 Easel 复制会话码，在 Chrome 扩展弹窗粘贴并点「检测当前页面并连接」。主应用会收到扩展连接状态；Chrome 不允许网页直接枚举已安装扩展，所以必须由扩展主动握手。
4. 回到 Easel 点「打开抖音创作者中心」。系统会新开作品管理页；用户本人在页面中扫码或登录。Easel 和扩展不接触登录凭证。
5. 登录后在作品管理 / 内容管理 / 视频列表页面打开扩展，点「检测当前页面并连接」。Easel 会显示未登录、找不到标签页、不支持页面或“可扫描”等状态。
6. 在扩展点「开始扫描历史作品」。每页完成滚动和读取后都会先保存检查点，再尝试翻页；翻页须观察到页码或作品列表变化才继续。无法识别下一页按钮或无法确认变化时，扫描会暂停并保留当前进度，请手动翻页后点「继续 / 恢复扫描」。
7. 扩展和 Easel 均可发起暂停、继续、结束或取消。关闭弹窗/浏览器或刷新页面后，重新打开扩展、粘贴同一会话码即可查看进度并从当前页面续扫。会话与检查点保留 7 天。
8. 完整扫描到末页后，点「生成预览（完成后切回 Easel 查看）」；预览生成后再切回 Easel 检查，可确认的完整 Snapshot 才能执行对账。扫描途中点「结束扫描并生成预览」后，扩展先保存当前页，再自动生成只读部分预览；看到“预览已送到 Easel”提示后切回 Easel。无需再点第二个按钮。部分预览不能确认同步、不能标记数据库记录缺失。

两个按钮的分工：结束按钮负责停止扫描并生成预览；生成预览按钮用于扫描已经结束时手动生成预览。结束请求尚在保存当前页时，预览按钮会等待结束；如果扩展弹窗曾关闭，重新打开后点生成预览会收敛挂起的结束请求并预览最后已保存的检查点。

## 读取字段

扩展只从页面 DOM 尝试读取作品 ID、标题、发布时间、视频时长、播放量、点赞、评论、收藏和分享。页面未显示的数据保持空值；页面明确显示 0 时保留为 0。作品主体、内容来源、Hook 和策略分类不会由扩展猜测。

页面结构由抖音控制，可能随版本变化。如果识别不到作品，请停止同步并改用 Easel CSV/XLSX 导入或手动录入。未扫描的页面不代表账号没有作品。

## 本地数据与访问范围

- 扩展仅有 `activeTab`、`scripting` 和 `storage` 权限，且只在用户主动打开扩展时读取当前标签页。
- 只向 `localhost:7860` 或 `127.0.0.1:7860` 发送检查点和预览数据；会话码 7 天有效并绑定抖音业务账号。
- 每页扫描记录持久保存在 Easel SQLite 会话表中；扩展将会话码与本地地址保存在 `chrome.storage.local` 以便重启恢复。
- 扫描只读取作品标题节点，忽略每条作品卡片里的编辑、权限和删除操作区。若创作者中心显示作品总数而扫描的唯一作品不足，Easel 会保留会话并暂停，不会报告扫描完成。
- Easel 在用户确认前不会将预览记录写入历史作品表；过期会话需回 Easel 重新创建。
